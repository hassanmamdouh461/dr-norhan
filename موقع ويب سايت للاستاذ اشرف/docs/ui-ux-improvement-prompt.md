# برومبت: استكمال خطة تحسين UI/UX لمنصة الأستاذ وليد (student-web)

انسخ اللي تحت ده كامل والصقه في جلسة جديدة:

---

أنت هتكمل خطة تحسين UI/UX متفق عليها لمشروع منصة تعليمية. اقرأ السياق كويس ونفّذ المراحل بالترتيب.

## السياق التقني
- المشروع: React 19 + Vite + TypeScript في `student-web/` (المسار الحالي)
- منصة تعليم لغة عربية للثانوية العامة (مصر) — RTL بالكامل، ثيمين: dark (الافتراضي) وlight
- Design tokens في `src/index.css` — الأساسي زمردي `--primary: 16 185 129` وكل الألوان متغيرات RGB بصيغة `rgb(var(--token))`
- الصفحات: `src/pages/Home.tsx` (داشبورد بتبويبات home/explore/my-courses/exams/qa/profile — ملف ضخم ~3700 سطر)، `LoginRegister.tsx`، `CourseDetails.tsx`، `LessonPlayer.tsx`، `LandingPage.tsx`
- مكونات جاهزة: `src/components/ui/Modal.tsx` (مودال موحد بـ Escape/overlay-close/role="dialog"/focus)، `Skeleton.tsx`، `Loader.tsx`، ToastContext (`showToast(type, title, message?)`)
- التشغيل: `npm run dev` على بورت 5173 (فيه `.claude/launch.json` جاهز) — الفحص: `npx tsc -b` والـ lint: `npx oxlint`

## شغل خلص بالفعل — متعيدوش
1. إصلاح الوضع الفاتح في Home (بروفايل/مودال الامتحان/الفوتر) بتحويل الألوان الثابتة لـ tokens
2. إزالة المحتوى الوهمي: عداد streak الثابت، زرار upvote الوهمي، progress bar الثابتة 100%، أرقام اللاندينج المزيفة
3. مودال الامتحان: autosave للإجابات في localStorage + تحذير قبل الإغلاق + عداد "أجبت X من Y" + تحذير التسليم الناقص + هيدر sticky
4. مسح كاش `cachedHomeData` عند تسجيل الخروج
5. كل imports الصور PNG اتحولت WebP
6. مودالات Home وCourseDetails متحولة لمكوّن Modal الموحد
7. أزرار السايدبار refactored لـ map واحد بكلاس `.sidebar-nav-item` + ARIA
8. توحيد المصطلحات على "المقررات"، عناوين صفحات ديناميكية، تحميل البيانات المتوازي + error state بزرار إعادة محاولة
9. هيرو صفحة تسجيل الدخول اتعمله redesign كامل بهوية "المخطوطة الزمردية" (شوف تحت)

## الهوية البصرية المعتمدة: «المخطوطة الزمردية»
دي الهوية اللي لازم تلتزم بيها في أي redesign جديد:
- **الألوان**: زمردي `rgb(var(--primary))` كأساس + ذهب مخطوطي كـ accent للتفاصيل فقط (dark: `#dcbb6d` / light: `#9a7b2d`) — الذهب للحدود الشعرية والفواصل والأيقونات الثانوية، مش للمساحات الكبيرة
- **الخطوط**: `Amiri` (متحمّل في index.html) للعناوين الكبيرة والكلمات الزخرفية فقط — كل الـ UI بخط Cairo
- **العناصر المميزة**: حد شعري متدرج زمردي→ذهبي بتقنية الـ mask (شوف `.auth-card::before` في LoginRegister)، أقواس معمارية للصور (`border-radius: 170px 170px 28px 28px` — شوف `.teacher-arch-frame`)، فاصل ذهبي بنقطة متوهجة (`.hero-gold-divider`)، كلمات عربية مشكولة عائمة بأوباسيتي منخفض مرسومة بالكود (`.hero-floating-words`)
- **الحركة**: staggered entrance بنمط `.hero-reveal` مع `animation-delay` متدرج + احترام `prefers-reduced-motion` دايماً
- **المرجع الحي**: سيكشن الهيرو في `LoginRegister.tsx` (الـ `<style>` المضمن فيه كل الأنماط بمتغيرات `--lh-*`)

## المراحل المطلوبة (نفّذ بالترتيب، وبعد كل مرحلة: tsc + معاينة بالمتصفح في الثيمين + commit)

### المرحلة 1 — استكمال صفحة تسجيل الدخول
- طبّق «المخطوطة الزمردية» على SECTION 2 (مزايا المنصة حول صورة المعلم) وSECTION 3 (المحاضرات والامتحانات المجانية) في `LoginRegister.tsx`: عناوين Amiri، فواصل ذهبية، كروت بحدود شعرية متدرجة، أيقونات ذهبية
- حوّل مودال الامتحان التجريبي المجاني (Public Exam Modal) في نفس الصفحة لمكوّن `Modal` الموحد بنفس ستايل الكارت الجديد

### المرحلة 2 — هيرو الداشبورد
- طبّق نفس الهوية على هيرو `Home.tsx` (نسختي الديسكتوب والموبايل): عنوان Amiri، استبدال الـ pegboard والـ taped notes بكروت بنفس لغة التصميم، توهجات زمردي+ذهبي
- صفحة `/landing` (LandingPage.tsx) مش مربوطة بأي تدفق أساسي — احذفها مع الـ route بتاعها من App.tsx لو مفيش استخدام فعلي ليها، أو وحّدها بنفس الهوية لو هتفضل

### المرحلة 3 — تفكيك Home.tsx (شرط قبل أي شغل إضافي عليه)
- قسّمه لـ `src/pages/dashboard/`: `DashboardLayout.tsx` (السايدبار + الهيدر + الـ bottom nav + المودالات المشتركة) و`HomeTab.tsx` / `ExploreTab.tsx` / `MyCoursesTab.tsx` / `ExamsTab.tsx` / `QaTab.tsx` / `ProfileTab.tsx` + hook اسمه `useDashboardData.ts` يشيل الداتا والكاش والـ loadData
- **صفر تغيير سلوكي**: نفس الـ routes ونفس الـ props ونفس الكاش

### المرحلة 4 — صفحة امتحان مستقلة
- route جديد `/exams/:examId` يحل محل مودال الامتحان: هيدر sticky (مؤقت + عداد إجابات + زرار تسليم)، شريط تنقل بين الأسئلة بحالة كل سؤال (مجاب/فاضي)، انقل نفس منطق autosave والـ guards الموجود حالياً، وخلّي زرار "بدء حل الامتحان الآن" يوجّه للصفحة

### المرحلة 5 — مكتبة مكونات + تنظيف الستايلات
- ابنِ في `src/components/ui/`: `Button` (variants: primary/secondary/ghost/danger + sizes)، `Card`، `Badge`، `EmptyState`، `SectionHeader`، `TextField/SelectField`
- استبدل الأنماط الـ inline المتكررة بالمكونات دي تدريجياً (ابدأ بالأزرار والبادجات — الأكثر تكراراً)
- انقل كل hover effects المكتوبة بـ `onMouseEnter/onMouseLeave` لكلاسات CSS `:hover`
- قسّم `index.css` (~3900 سطر) لـ: `styles/tokens.css` / `styles/base.css` / `styles/components.css` / `styles/pages/*.css` واحذف الستايلات الميتة (pegboard، taped-notes، fusha-matrix، أي كلاس مش مستخدم — اتأكد بـ grep قبل الحذف)

### المرحلة 6 — البروفايل والموبايل
- أعد تنظيم تبويب البروفايل لتبويبات فرعية: بياناتي / الأمان والأجهزة / المدفوعات / نتائجي
- احذف عرض سجل المشاهدة الخام (playback logs بصيغة "بدء المشاهدة (313 ثانية)") أو حوّله لسطر مفيد ("واصلت المشاهدة من الدقيقة 5")
- قلّص الـ bottom nav في الموبايل لـ 5 عناصر (الرئيسية/المقررات/مقرراتي/الامتحانات/ملفي) وانقل الاستفسارات لزرار عائم أو جوه البروفايل

### المرحلة 7 — أداء وتفاصيل أخيرة
- lazy loading لبيانات التبويبات: متحمّلش داتا تبويب (أسئلة/ماليات/أجهزة...) غير عند أول فتح ليه
- Material Symbols: استبدله بـ subset للأيقونات المستخدمة فعلاً أو SVG sprite (حالياً بيتحمّل الخط كله بـ display=block)
- مراجعة تباين (contrast) شاملة في الثيمين + تأكد إن كل عنصر تفاعلي عنده `:focus-visible` واضح

## قواعد إلزامية — ممنوع كسرها
1. **متغيّرش أي logic**: الـ auth والـ API calls والحسابات زي ما هي — التغييرات presentational إلا المذكور صراحة (المرحلتين 3 و4 إعادة هيكلة بدون تغيير سلوك)
2. **دومين البريد المُولَّد من رقم الهاتف هو `@fusha.edu.eg`** (في AuthContext و LoginRegister) — ده وظيفي (تحويل رقم الهاتف لإيميل Supabase). ⚠️ أي حساب اتعمل بالدومين القديم لازم يتم ترحيله قبل النشر، وإلا مش هيقدر يسجّل دخول برقم الهاتف
3. كل لون جديد من الـ tokens أو متغيرات `--lh-*` — **ممنوع** hex/rgba ثابتة جديدة، وكل عنصر جديد لازم يتشاف ويتقري في الثيمين dark وlight
4. RTL دايماً: أسهم الرجوع `arrow_forward` (مش `arrow_back`)، والاتجاهات كلها صح
5. بعد كل مرحلة: شغّل `npx tsc -b` ثم السيرفر وتحقق في المتصفح (ديسكتوب 1440 + موبايل 375، الثيمين) قبل ما تنتقل للمرحلة اللي بعدها
6. commit منفصل لكل مرحلة برسالة واضحة — ومتعملش push من غير إذن
