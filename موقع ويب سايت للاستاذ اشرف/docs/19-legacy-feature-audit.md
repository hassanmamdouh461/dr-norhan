# تدقيق المزايا القديمة وقرار الدمج

تم فحص الأرشيفات الأربعة قراءةً فقط دون فكها داخل المصادر أو تعديلها.

## backend.zip

Express/TypeScript/MongoDB قديم، ويحتوي نماذج وخدمات ومسارات للطلاب والمدرسين والمحاضرات والاختبارات والمراحل والمواد والمدن والألوان. لم يُنسخ الباكند القديم لأن Cloudflare Worker + D1 الحالي أكثر ملاءمة، واستُخدمت المزايا كمرجع وظيفي.

## dashboard.zip

لوحة React قديمة لإدارة الطلاب والمدرسين والمحاضرات والاختبارات والمواد. لوحة Next الحالية تغطي هذه المجالات بهيكل أحدث، مع أكواد التفعيل والتحليلات وإدارة الأجهزة والفيديو.

## platform-exams.zip

منصة اختبارات ويب مستقلة تضم تدفقات الامتحانات والأسئلة والإجابات والصور والإعدادات. المزايا المقابلة موجودة في النسخة الجديدة عبر صفحات `dashboard/exams` و`dashboard/questions`، واجهة الطالب `ExamsTab` و`ExamModal` و`QuizPanel`، ومسارات Worker وهجرات `0007` و`0008` و`0012` و`0013` و`0015`.

## TestingApp.zip

تطبيق اختبار/طالب قديم استُخدم لمقارنة رحلات الاستخدام فقط. لم يُنسخ أي Flutter أو build output إلى المنصة الجديدة.

## تغطية المنصة الجديدة

- التسجيل، الدخول، استرجاع الجلسة والملف الشخصي.
- الدورات والوحدات والدروس والتقدم والاستكمال.
- HLS محمي بعلامة مائية وروابط تشغيل موقعة، مع Bunny → R2 والحفاظ على مسارات Bunny الحالية.
- الاختبارات، بنك الأسئلة، الخيارات والإجابات وصور السؤال والإجابة والإعدادات المتقدمة.
- أكواد التفعيل، الإشعارات، الأسئلة والأجوبة.
- لوحة إدارة للمحتوى والطلاب والإحصاءات والأسئلة والاختبارات والأكواد والأجهزة والفيديو.
- Cloudflare Pages/Functions وWorker وD1 migrations وR2 وKV وQueues وقوالب البيئة.
