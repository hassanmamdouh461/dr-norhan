# 📖 منصة فُصْحَى | أستاذ أشرف سليم — خبير تدريس اللغة العربية

صفحة هبوط (Landing Page) عصرية وتفاعلية مصممة لطلاب الثانوية العامة وأولياء الأمور مع خلفية فيديو سينمائية، ومودال تفاعلي، وتصميم متجاوب بالكامل باللغة العربية (RTL).

## 🚀 المميزات الفنية
- **خلفية فيديو بالهيرو سكشن:** فيديو عالي الجودة مع طبقات تعتيم متعددة لضمان وضوح وقراءة النصوص والأزرار.
- **مودال تفاعلي بالصوت الكامل:** إمكانية فتح فيديو الرسالة بالصوت الكامل بضغطة زر.
- **فورم حجز ذكي:** يحول بيانات الطالب تلقائياً إلى رسالة واتساب منسقة ومباشرة.
- **متجاوب 100%:** تصميم سلس على الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر.
- **الأداء والسرعة:** مبني باستخدام HTML5 و Tailwind CSS بدون أي بطء أو تبعيات ثقيلة.
