استفسار بخصوص معادلة شرودنغر في البعد الواحد

Ψ(x) = A sin(kx) + B cos(kx)

لكنني لا أفهم لماذا يتم استبعاد الحد الثاني (B cos(kx)) عندما يكون الجهد لانهائي عند الأطراف.
