# 🎓 الدكتور في الفيزياء — منصة تعليمية متكاملة

> منصة تعليمية احترافية لمدرّس الفيزياء: تطبيق موبايل للطلاب لمشاهدة الشروحات
> بفيديو محمي من التحميل وتسجيل الشاشة، ولوحة تحكم ويب للمدرس لرفع وتنظيم المحتوى.

**هذا المجلد يحتوي على التوثيق الكامل للمشروع فقط (تصميم ومواصفات) — بدون أي كود فعلي.**

---

## 📌 ملخص المشروع

| البند | القرار |
|---|---|
| **اسم المشروع** | الدكتور في الفيزياء (Dr. Physics) |
| **منصة الطلاب** | تطبيق موبايل فقط — Android + iOS (Flutter) |
| **لوحة تحكم المدرس** | موقع ويب (Cloudflare Pages) مرتبط بنفس الباكند |
| **الباكند** | Cloudflare بالكامل: Workers + D1 + R2 + KV + Queues |
| **المصادقة** | Supabase Auth فقط (إيميل/باسورد + دور Admin) |
| **استضافة الفيديو** | Bunny Stream (ترميز سحابي) ← Cloudflare R2 (بث HLS مشفّر) + خيار رابط YouTube (طبقة أخف) |
| **حماية الفيديو** | منع التحميل + منع تسجيل الشاشة + علامة مائية ديناميكية + DRM |
| **نموذج الوصول** | أكواد تفعيل فقط (بدون بوابة دفع أونلاين) |
| **النطاق (Domain)** | ساب دومين على `synapticstudio.tech` |
| **اللغة** | عربي أولًا (RTL) + دعم إنجليزي |

---

## 🌐 النطاقات (Subdomains)

| النطاق | الغرض | الاستضافة |
|---|---|---|
| `dr-physics.synapticstudio.tech` | لوحة تحكم المدرس (Dashboard) | Cloudflare Pages |
| `api.dr-physics.synapticstudio.tech` | واجهة الـ API الخلفية | Cloudflare Workers |
| `videos.dr-physics.synapticstudio.tech` | نطاق مخصص لبث شرائح HLS من R2 | Cloudflare R2 |

> التطبيق (الموبايل) يستهلك `api.dr-physics.synapticstudio.tech` مباشرة.

## ⚠️ ملاحظة مهمة حول حماية الفيديو

لا توجد حماية برمجية تمنع تسجيل الشاشة بنسبة 100% (تظل الكاميرا الخارجية ممكنة).
الهدف هو **رفع تكلفة التسريب لأقصى درجة عمليًا** عبر طبقات متراكمة:
منع التحميل المباشر + DRM + منع تسجيل الشاشة على مستوى نظام التشغيل + علامة مائية
ديناميكية باسم/رقم الطالب + ربط الجهاز + كشف الـ Root/Jailbreak. التفاصيل في
[docs/08-video-protection.md](./docs/08-video-protection.md).
