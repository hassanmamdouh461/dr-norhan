# 📖 منصة وتطبيق فُصْحَى (الأستاذ أشرف سليم)
## دليل حزمة الهوية البصرية ونظام تصميم الواجهات (UI/UX Design System Package)

مرحباً بك في الحزمة الهندسية الكاملة للهوية البصرية ونظام تجربة المستخدم (UI/UX) الخاصة بتطبيق ومنصة **«فُصْحَى»** للأستاذ **أشرف سليم** (مادة اللغة العربية للثانوية العامة بمصر).

تم إعداد هذه الحزمة وفق أعلى المعايير القياسية لنظم التصميم (Design Systems) وهندسة الواجهات لتكون جاهزة للتنفيذ المباشر بواسطة نماذج الذكاء الاصطناعي (AI Coding Agents) أو مطوري الواجهات (Flutter & Web).

## 🚀 كيفية البدء بالتنفيذ (How to Proceed)

1. **إذا كنت تستخدم نموذج ذكاء اصطناعي (AI Agent):**  
   وجّه النموذج بقراءة ملف `AI_AGENT_INSTRUCTIONS.md` وملف `IDENTITY_AND_DESIGN_SYSTEM.md` أولاً قبل كتابة أي كود للشاشات.
2. **لتطبيق فلاتر (Flutter):**  
   انسخ ملف `theme_tokens.dart` داخل مجلد `lib/core/theme/` واستخدم `FushaTheme.lightTheme` مباشرة.
3. **لتطبيق ويب (Next.js / React / Tailwind):**  
   أضف `tailwind_brand_preset.js` إلى مصفوفة `presets` في ملف `tailwind.config.js`.
